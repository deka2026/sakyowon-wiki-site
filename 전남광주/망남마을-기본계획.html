사업 개요

항목내용

3대 사업영역생활서비스 개선 / 경제생태계 조성 / 정주환경(어항) 개선

마을 현황

인구·세대

  • 81세대 145명 거주, 군내리(법정리) 소속 행정리
  • 2014→2024년 인구 64명(29%) 감소
  • 완도군 자연증가율 −13.9% (2022), 인구성장률 −2.1%
  • 완도 더테라스 시그니처 (군내리 산76, 256세대 / 2027년 준공) 입주 시 인구 5.2배 증가 예상 (145명 → 732명)

어업 기반

  • 마을양식장 198ha (해조류 60 / 패류 38 / 복합 100)
  • 전복 가두리 35ha = 12,145칸, 연평균 420t 생산
  • 망남리는 완도읍 전복생산량의 약 80% 차지
  • 해양생태도 1등급 권역
  • 작업 패턴: 새벽 45시 시작 ~ 오후 23시 마무리

태풍 피해 이력

  • 2012 볼라벤: 해상 전복 가두리 전면 파손 (30가구 11,000칸 표류)
  • 2018 솔릭: 가두리 시설 유실, 전복 생산량 2/3 이상 폐사

전복 유통 구조 문제

  • 산지 도매상 거치는 출하가 80% 이상
  • ‘덤’ 관행: 폐사 명목 30% → 개선되어 10% 수준
  • 2015→2023: 전국 전복 생산량 2배, kg당 가격 42,000원→27,000원 (35.7% 하락)
  • 망남리 산지가격 (2023): 20미 1kg당 약 18,000원 (생산비 22,000원 → 적자)
  • 500여 어가 파산 전망

생활서비스 접근성

분야등급(10등급제)평가
교육9–10확대 필요
노인복지8–9확대 필요
기초의료9–10확대 필요
생활편의9–10시급
문화1양호

지역사회 5대 핵심의제

  1. 주민 참여형 건강관리 네트워크 (질환 보유 50%, 의료접근성 제약)
  2. 주민 주도 교육·돌봄 공동체 (마을 선생님 수요 높음)
  3. 세대통합 문화·복지 프로그램 (청년 공간 부재)
  4. 주민 참여 기반 지역경제 생태계 (전복 유통 개선)
  5. 주민 기획 관광 콘텐츠 (해양관광 자원 vs 즐길거리 부재)

사회혁신프로그램 (2023~2024 시범)

  • 망남 건강관리실 (어민 근골격, 고령층 동행)
  • 망남 마을학교 (드론 미디어, 다육이 문화교양)
  • 로컬콘텐츠 발굴, 해양치유, 커뮤니티 공간 조성
  • 구독경제 시범 (전복 공동구매)

링커조직 (외부 협력)

  • 조선대병원 어업안전보건센터 (전국 유일 어업인 특화 의료기관)
  • 광주의료사회적협동조합 (마을 단위 건강관리 경험)
  • 모두의마을미디어협동조합 (청년 미디어 인력)
  • 전남영상위원회 (MOU 체결)
  • 위스테이별내사협 (“백개의 학교” 운영 경험)
  • HBM, 스마일아일랜드 (전복 가공·유통)
  • 도시공동체 10개소 (구독경제 판로)

순환 구조 모델

경제활동 → 수익 발생 → 수익 10% 공동기금 적립 → 마을학교·건강관리실 투자 → 정주여건 개선 → 인구 유입 → 경제 확대

거점시설 3개소

시설기능주 수혜층
교육문화스테이션 (리모델링, 309.6㎡)교육·문화·건강관리아동·청소년·중장년
망남활력스테이션 (신축, 805.98㎡)전복 작업·유통·어민 다목적어업인
망남리복지센터 (기존)돌봄스테이션고령층

교육문화스테이션

  • 구 특산품판매장 리모델링 (지상 2층 + 옥상)
  • 외장: 라임스톤·화강석 / 옥상: 태양광·풍력 + 데크
  • 연간 유지관리비 약 916만원
  • 운영주체: 망남새마을회 (향후 법인화 예정)

망남활력스테이션

  • 경량철골조 + 방파제 인접 부지
  • 1F 전복양식 공동작업장 (5m 차량통로)
  • 2F 어촌계 사무실 + 어민다목적실 + 옥상정원
  • 연간 유지관리비 약 2,000만원
  • 운영주체: 망남어촌계

S/W 사업 6개

  • B1 망남 건강관리실 (인력육성 / 방문보건 / 건강프로그램)
  • B2 망남 마을학교 (마을지도사 / 거점형 운영 / 에너지생태 캠프)
  • B3 생산자 주도 유통체계 (판로개척 / 브랜딩 / 마케팅·가공품)

H/W 시설 — 망남방파제 정비

  • 현재: L 170m, B 4m (표준 10m 미달)
  • 목표: 외측 사석경사제식 2m 확장 → 폭 6m
  • 방파제 끝단 회차공간 10×12m 신설
  • TTP(테트라포드) 보강 — 적용 중량 1,016톤
  • 파고 2m 이상 일수 약 80일/년

거버넌스 — 망남신활력 운영위원회 (13명)

  • 지역협의체 4명 + 망남새마을회 3명 + 망남어촌계 3명 + 집합주거 입주자 1명 + 행정/앵커
  • 산하: 생활서비스 분과 + 경제생태계 분과

성과지표

  1. 정주만족도: 5영역 20문항 (주거·인프라·관계·경제·문화)
  2. 마을인구수: 상주/생활/관계 인구 세분화 + 모바일 빅데이터
  3. 소득분배: 지니계수 + 5분위 + 마을기금 조성·배분
