세션 요약

이사장님 지시로 네 갈래 작업을 수행했다. ① 어촌계·행정리 마을회 표준규약을 조사해 인쇄용 문서 2종을 만들었고, ② 친환경 소각장 6개 사례를 병렬 조사해 상세 보고서를 냈으며, ③ 사교원 관련 사이트 전체의 지역 표기를 “전남광주통합특별시”로 통일했고, ④ 27개 시군구 고향사랑기부제 정보 사이트(hometown-love)를 새로 구축·배포했다. 산출물 전달 채널은 GitHub 커밋 + raw URL 방식으로 확정됐다.

작업 1 — 표준규약 인쇄용 문서 (sakyowon-site)

  • docs/마을규약/행정리_마을회_표준정관(안).html (커밋 99013bb) — 전 25조. 행안부는 전국 단일 표준정관을 고시하지 않으며, 실체는 각 시군 「마을회 육성·지원 조례」 별표와 비법인사단 등록(부동산등기용등록번호) 서식임을 확인하고 공통 골격으로 작성.
  • docs/마을규약/어촌계정관(예)_표준안.html (커밋 5085f77) — 전 29조. 근거: 해양수산부고시 제2017-116호 「어촌계정관(예)」 + 수협법 제15조. 정본은 수협중앙회 어촌사랑 누리집에서 hwp 배포.
  • 두 문서 모두 브라우저에서 열어 인쇄 버튼(A4/PDF)으로 출력하는 방식. 노란 음영은 채움 칸.
  • 상태: 완료·배포. 망남 관할 지자체명을 받으면 음영 칸을 실제 값으로 채우는 후속 작업 가능.

작업 2 — 친환경 소각장 사례조사 보고서 (sakyowon-site)

  • docs/조사보고/친환경_소각장_사례조사_보고서.html (커밋 dd837d7) — 6개 사례 각 3쪽 분량 + 정책·기술 동향 + 폐촉법 조문↔사례 매핑.
  • 병렬 조사 에이전트 6개로 교차검증. 그 과정에서 웹 요약 단계의 오류 4건을 정정: 안양 현대화는 201213년(202123 아님), 용인 사업비 3,850억+편익 500억(5,000억 아님), 천안은 자체 대체시설(아산은 접경 협상 당사자), 마포 신규 1,000t은 2026.3 백지화(입지선정위 구성 절차 하자).
  • 상태: 완료·배포.

작업 3 — 전남광주통합특별시 명칭 통일 (4개 레포)

  • sakyowon-site 0b10a97 / sakyowon-hub 320dc80 / mangnam-coop ca119e7(+gh-pages 재빌드·배포, 라이브 확인) / mangnam-vitality f807ba0.
  • 원칙: “광주광역시·전라남도·전북특별자치도” → “전남광주통합특별시·전북특별자치도”(전북은 별도 유지), 주소는 “전남광주통합특별시 완도군 …” 체계.
  • 위키는 의도적으로 제외 — 과거 공문서 파일명·회계 기록은 원본 기록이라 변경하면 훼손.
  • mangnam-vitality는 서버 구동형이라 지미에게 재빌드 요청 편지 남김(JIMMY-DECA.md, 커밋 97fcb86). 이미 배포된 상태라면 git pull && npm run build 후 재시작 필요.
  • 상태: 정적 사이트 3종 라이브 반영 확인, vitality만 지미 처리 대기.

작업 4 — 고향사랑기부제 정보센터 사이트 (신규 레포 hometown-love)

  • 레포: deka2026/hometown-love (커밋 f69a723), 라이브: https://deka2026.github.io/hometown-love/ (Pages, main 브랜치 루트). 허브에 카드 추가(12500b5).
  • 구조: 클릭형 SVG 지도(southkorea-maps GeoJSON에서 전남 36xxx·광주 24xxx 27개 추출·투영) → 시군구별 운영현황 페이지 + 답례품 하위 페이지. 정적 생성기 build/make_data.py(데이터) + build/gen.py(생성) — 데이터 수정 후 두 스크립트 실행하면 전체 재생성.
  • 데이터: 조사 에이전트 3개(전남 서부 11/동부 11/광주 5+제도)로 수집, 연도별 모금액·기금사업·지정기부·답례품 125종+. 하이라이트: 2025년 전국 기초 1위 광주 남구(71.35억)·2위 동구(64.08억), 전남 시도 3년 연속 1위(239.7억), 담양 군 단위 1위, 영암 지정기부 1위(소아청소년과 개원).
  • 한계(사이트에 명시): 답례품 개별 가격·업체 연락처는 고향사랑e음 동적 페이지에서만 조회 가능한 경우가 많아 확인분만 수록. 광양·구례·장성 등 일부 모금액은 행안부 비공개로 미확인.
  • 상태: 완료·라이브 확인. 후속 후보: 고향사랑e음 시군구별 몰에서 가격·연락처 보강.

레슨

  1. 웹 검색 요약을 그대로 믿지 말 것. 검색 툴의 요약이 연도·금액·주체를 틀리게 준 사례가 이번 세션에만 4건(작업 2 참조). 보고서급 산출물은 반드시 원문 기사/공식 페이지를 열어 교차확인해야 한다.
  2. 산출물 전달은 GitHub 커밋 + raw URL이 정답. 임시 http 서버(포트 개방 필요)보다 이사장님이 선택한 방식. 한글 파일명 raw URL은 퍼센트 인코딩해서 제공.
  3. gh CLI가 시스템에서 사라질 수 있다. 2026-07-30 세션 재시작 후 /usr/bin/gh 소멸 → /.local/bin에 유저 레벨로 재설치하고 git 글로벌 credential helper 경로를 갱신해 복구했다. 토큰(/.config/gh/hosts.yml)은 살아 있었다. 다음에 push 인증 오류가 나면 which gh부터 확인.
  4. 기록물(위키 원본·파일명)은 일괄 치환 대상에서 제외하는 판단을 명시적으로 보고할 것 — 이번엔 문제없이 수용됨.
  5. mangnam-coop 배포는 gh-pages 브랜치(legacy Pages)다. 소스만 푸시하면 라이브에 반영되지 않는다 — npm run build 후 out/을 gh-pages에 커밋해야 한다. 다른 배포 주체(지미)가 먼저 푸시했을 수 있으니 push 거부 시 원격 커밋을 확인하고 reset 후 재커밋.
