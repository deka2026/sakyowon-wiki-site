이번 세션에서 한 일 (전부 라이브 반영 확인)

아카데미 사이트(deka2026.github.io/academy-site)의 AI 학습 가이드 메뉴를 대개편했다. 커밋 97055b7, 23d2f74.

1. 바이브 코딩 1부·2부 개념 통합

activist.poomasi.org의 「바이브 코딩의 개요(1부)」·「바이브 코딩 2부(하네스)」를 접이식 카드로 통합. 기존 컨셉(개념 안내 → 진행 현황 → AI 학습 대화)은 유지.

  • 1부: 4단계 지도(도구→프론트→백엔드→배포) + 카드 5개 + 3줄 요약
  • 2부: 하네스 네 기둥 + MD·스킬·MCP·API·에이전트·루프 카드 6개 + “판단의 자리에 사람 두기” 원칙

2. 실습 11단계 → 15단계 확장

하네스 실습 4단계 신설: 12 스킬 만들기(위키발행 스킬), 13 커넥트 MCP(GitHub 연결), 14 에이전트 분업(Maker·Checker), 15 반자동 트리아지 루프(AI는 분류만, 판단은 사람). 개념 카드마다 대응 실습 단계로 연결. 기존 수료자는 11/15로 표시되고 이어하기로 12단계부터 진행.

3. 학습 대화 UX 보강

  • 시작 전 점검: 2~15단계 시작 시 이전 단계가 제대로 됐는지 확인하는 명령을 먼저 안내 (예: Git 단계 전 node --version)
  • “이전 단계” 입력으로 전 단계 되돌아가기
  • 중간 단계 시작: 진행 배지 클릭 또는 “3단계부터 시작” 입력으로 점프

4. 메뉴 분리 (같은 날 후속 작업)

“AI 학습 가이드” 단일 메뉴를 학습개요(개념 1부·2부 + 실습시작 CTA)와 실습시작(진행 현황 + AI 학습 대화 15단계) 두 메뉴로 분리. 개념 카드의 실습 참조 9곳은 실습시작 이동 링크로 전환, 기존 학습 진도는 유지. 커밋 6a9ce20.

5. 이 위키(sakyowon-wiki) 보안 정리

  • npm audit fix로 취약점 9건(high 7) → 0건, Quartz 빌드·배포 정상 (커밋 e7f73df)
  • GitHub 기본 브랜치를 v5(업스트림 미러) → **v4(실제 작업 브랜치)**로 변경 — Dependabot 유령 경고 17건 해소, 열린 알림 0건
  • 배포 워크플로 액션 업그레이드(checkout·setup-node v7, upload-pages-artifact·deploy-pages v5)로 Node.js 20 종료 경고도 해소 (커밋 564b0d1)

6. [아카데미] 검증 게임 → “연대지능기여게임” 명칭 변경

사이드바·페이지 제목·OG 메타·버튼·퀴즈 문항 등 10곳 교체 (커밋 0852ce5). 내부 id와 저장 데이터는 그대로, “내 검증 기록” 메뉴명은 유지(이사장 결정).

7. [허브] 모바일 홈 화면 바로가기(PWA) 지원

sakyowon-hub에 manifest + 아이콘 4종(초록 원 社) + 캐시 없는 최소 서비스워커 + “홈 화면에 바로가기 추가” 버튼 추가 (커밋 e5cbe34). 안드로이드는 설치 팝업, iOS는 공유→홈 화면 추가 안내.
