핸드오버 2026-09-28 — 한글문서 서식 집 규칙과 해바람물자산재단 제안서 v2.2

세션 요약

전남광주해바람물자산재단 설립제안서 v2.1을 고치려고 문서를 열었다가, 이사장님이 서식 자체를 바꾸라고 지시하셨다. 문단이 내어쓰기로 되어 있어 둘째 줄부터 오른쪽으로 밀려 보이던 것을 들여쓰기로 뒤집고, 목차 번호 앞의 네모칸(□) 49곳을 모두 없앴다. 이 규칙을 앞으로 만드는 모든 한글문서에 적용하라고 하셔서, 메모리에 적는 데 그치지 않고 hwpx 생성기 세 곳에 직접 배선했다. 문서 내용 수정은 아직 시작하지 않았다.

작업 1 — 사이드바 정리

데스크톱 앱 사이드바에서 deka_chat 목록을 위로 올려 달라는 요청. 보기 설정은 이미 「프로젝트별 그룹 + 최근활동순」이라 바꿀 것이 없었다(changed: 0). 확실하게 올리는 방법으로 고정(Pinned) 을 제안해 승인받고, deka_chat 세션 11개(현재 세션 포함)를 고정했다. 고정 항목은 모든 그룹 위 Pinned 구역에 뜨고, 자동 보관 대상에서도 빠진다.

작업 2 — 해바람물자산재단 설립제안서 v2.2

산출물: 같은 폴더에 전남광주해바람물자산재단_설립제안서_v2.2_20260928.hwpx 와 .pdf. 원본 v2.1은 손대지 않고 보존했다.

고친 것은 서식 두 가지뿐이고 본문 내용은 한 글자도 바꾸지 않았다.

표를 담는 문단의 음수 intent 때문에 표가 본문보다 왼쪽으로 튀어나와 있었다. 0으로 맞추니 본문과 나란히 선다. 표 폭 47622가 본문 폭 48188보다 작아 오른쪽으로 넘치지 않는 것을 먼저 확인하고 옮겼다.

검수: 한글 2024로 직접 열어 PDF를 뽑고(pagecount_auto.ps1 -Pdf) PyMuPDF로 1쪽·3쪽을 렌더해 눈으로 확인했다. 36쪽 → 36쪽으로 쪽수가 그대로여서 넘친 곳이 없다.

  • 레슨: ~/workspace/knowledge/lessons/한글문서-문단여백-집규칙.md, knowledge/INDEX.md 33행에 반영.
  • 자동메모리: feedback_hwp_paragraph_format.md.

레슨

1. 내어쓰기를 뒤집을 때는 intent 와 left 를 함께 옮긴다. 한글의 계산은 첫 줄 = left + intent, 나머지 줄 = left 다. intent 만 0으로 만들면 left 가 남아 문단 전체가 오른쪽으로 밀린다. 단위는 HWPUNIT이고 1pt = 100이므로 12pt 글자 두 개가 2400이다.

2. intent 를 일괄로 넣으면 안 된다. 제목과 표까지 들여써져 문서가 흐트러진다. 문단의 역할별로 값을 갈라 줘야 한다.

3. □ 제거는 뒤따르는 런의 앞 공백까지 지운다. 생성기가 □ 를 별도 런으로 찍고 다음 런을 1. 제목 으로 시작하기 때문에, 런만 지우면 번호 앞에 공백이 남는다.

4. WSL 셸의 PATH 에 powershell.exe 가 없다. /mnt/c/Windows/System32/WindowsPowerShell/v1.0/powershell.exe 전체 경로로 불러야 한다. 이걸 모르고 powershell.exe 만 치면 “윈도우 도구를 못 쓴다”고 잘못 판정하게 된다. 이 기계에는 한글 2024가 설치돼 있어 WSL에서 PDF 변환까지 끝낼 수 있다.

5. 후처리기를 돌릴 때 --no-font 를 빼면 안 된다. 집 규칙 1번(본문 12pt 이상)이 함께 돌아, 이미 완성된 문서의 간격문단(6pt)과 표머리(11pt)까지 12pt로 키워 레이아웃을 망친다. 서식만 손볼 때는 --no-font --no-tables --no-cells-left 를 붙인다.

6. 「기억해」 지시는 메모리가 아니라 도구에 넣는다. 생성기가 규칙을 지키면 다음 세션이 규칙을 몰라도 결과가 맞는다.

미완료

  1. 해바람물자산재단 설립제안서 v2.2의 내용 수정 — 데카. 서식만 고쳤고 본문은 그대로다. 이사장님께서 어느 장의 무엇을 고칠지 아직 지시하지 않으셨다. 직전 핸드오버(handover-20260925-haebaram-foundation-v21-and-decree-opinion.md)에 남아 있던 항목은 파란 글씨 확정 14곳, 설비 단가 kW당 130만 원과 7.7GW 기준 시나리오의 출처 확정, 확인 과제 23건 중 포럼 단계 즉시 항목(대부업 금융위 질의, 주무관청 특정, 기부 대가성 국세청 질의)이다.

  2. v2.2에 적용한 서식을 다른 확정 문서에도 소급할지 결정 — 이사장님. 같은 폴더의 시행령 의견서(사회연대경제기본법_시행령_의견서_20260925.hwpx)와 세부사업 계획서 12종은 아직 옛 서식이다. 소급하라고 하시면 hwpx_house_rules.py --no-font --no-tables --no-cells-left 로 일괄 처리할 수 있다.

  3. 위키의 content/코어법인/사교원_사명선언문.md 에 커밋되지 않은 수정이 남아 있다 — 확인 필요. 이번 세션에서 만든 것이 아니고, 2026-09-28 사명선언문·HWPX 레이아웃 세션의 작업으로 보인다(63줄 추가·37줄 삭제). 내용은 완성돼 보이지만 남의 세션 작업을 임의로 올리지 않았다. 의도한 것이면 커밋하면 되고, 아니면 되돌리면 된다.

  4. md-to-hwpx-docset 의 house_format() 은 실제 문서로 돌려 보지 않았다 — 데카. 구문 검사만 통과했다. 다음에 그 생성기로 문서를 만들 때 산출물을 한 번 눈으로 확인할 것.
