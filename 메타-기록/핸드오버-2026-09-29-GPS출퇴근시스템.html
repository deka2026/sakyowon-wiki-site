핸드오버 2026-09-29 — GPS 출퇴근·휴가결재 시스템 구축과 이사장 1~9월 근무자료 이관

세션 요약

완도군 군내리 사무실을 중심으로 정해진 반경 안에서만 출퇴근이 찍히는 근태 시스템을 새로 만들어 work.sakyowon.co.kr 로 개통했다. 출퇴근 기록뿐 아니라 연가·대체휴가·기타휴가 신청과 관리자 결재, 직원별 근무요일·근무시간·주5일 대비 근무 비율 설정, 기록 내려받기와 누락 보정까지 한 화면에 들어 있다. 그 위에 이사장님의 2026년 1~9월 근무 자료(D 드라이브 월간보고 엑셀 9개)를 읽어 실제 데이터를 채워 넣었다. 시험이 아니라 운영에 들어간 상태이며, 남은 것은 현장에서 GPS 중심 좌표를 한 번 찍는 일과 직원 등록이다.

1. 근태 시스템 — 만든 것

집 관례를 그대로 따랐다. FastAPI + sqlite + 정적 PWA 한 장, uvicorn 은 127.0.0.1 에만 붙고 클라우드플레어 터널이 바깥을 맡는다. 의정소통(talk)과 같은 구조다.

무엇어디
앱/opt/sakyowon/work/app.py (FastAPI, 약 1,000줄)
화면/opt/sakyowon/work/static/index.html (PWA 한 장, 바닐라 JS)
DB/opt/sakyowon/work/data/work.db (sqlite, WAL)
서비스sakyowon-work.service → 127.0.0.1:8792, enabled
주소https://work.sakyowon.co.kr (터널 sakyowon-wando ingress + CNAME)
첫 관리자·PIN 초기화python3 /opt/sakyowon/work/관리.py 관리자 "이름" 010-....
주소 개통·되돌림`python3 /opt/sakyowon/work/개통.py [—실행
DB 백업/opt/sakyowon/work/data/백업/work-YYYYMMDD-HHMMSS.db (sqlite backup API)

기능은 다음과 같다.

  • GPS 출퇴근 — 하버사인으로 중심에서의 거리를 재고 반경 밖이면 막는다. GPS 오차가 허용치보다 크면 역시 막는다(허공에서 찍히는 것을 방지). 찍힌 거리와 오차를 기록에 남긴다.
  • 홈 화면 바로가기 — manifest + service worker + 아이콘 4종. 아이폰은 공유→홈 화면에 추가, 안드로이드는 앱 설치. 껍데기만 캐시하고 근태 기록은 절대 캐시하지 않는다.
  • 로그인 — 휴대폰번호 + PIN. 초기 PIN 은 번호 뒤 4자리이고 첫 로그인에서 변경을 강제한다. PBKDF2 210,000회, 세션 쿠키는 httponly·secure·samesite=lax.
  • 신청·결재 — 연가, 반차(0.5일), 대체근무, 대체휴가, 기타휴가. 관리자가 올린 신청은 그 자리에서 결재까지 끝난다. 잔여가 모자라면 승인 단계에서 막힌다.
  • 관리자 — 직원 CRUD, 직원별 근무요일·출퇴근시각·주5일 대비 근무 비율(%)·연가 일수 설정, 결재함, 기록 보정·삭제, 빠진 기록 찾기, CSV 3종 내려받기, 현장 좌표·반경·지각 유예·휴게시간 설정, 공휴일 등록.

2. 정해진 규칙 (이사장님 확정)

  • 로그인은 휴대폰번호 + PIN 4자리. 문자 발송 설비가 없어 OTP 는 쓰지 않는다.
  • 대체휴가는 1일 근무 = 1일 적립. 시간 단위 환산을 쓰지 않는다.
  • 연가 일수는 관리자가 직원별로 직접 입력한다. 입사일 기준 근로기준법 자동 계산을 쓰지 않는다.
  • 이사장님 근무시간은 08:00~17:00, 나머지 직원은 09:00~18:00(등록 창 기본값).

3. 검증

실서버에 그대로 태우는 하네스를 짜서 돌렸다(모킹 없음). 41건 전부 통과를 로컬(127.0.0.1:8792)과 라이브 HTTPS(work.sakyowon.co.kr) 양쪽에서 확인했다. 반경 밖 차단, GPS 오차 과다 차단, 중복 출근 차단, 출근 없는 퇴근 차단, 잔여 부족 시 승인 거부, 직원의 관리 API 접근 차단, CSV 인코딩까지 들어 있다. 하네스는 /tmp 세션 폴더에 있었으므로 영구 보관하려면 다시 만들어야 한다 — 다만 아래 「스킬」에 절차를 남겼다.

주소 개통 뒤 같은 터널의 다른 호스트 9개(sakyowon.co.kr·talk·home·bid·vitality·deka·api·svc·www)가 모두 정상 응답하는 것을 확인했다.

4. 이사장님 1~9월 근무자료 이관

원본은 /mnt/d/2026 사업/월간보고/일영 근무 현황/ 의 월별 엑셀 9개 (사회혁신교육원사회적협동조합-김일영_2026-MM-01-...xlsx)다.

들어간 것건수
근태 기록208일 (2026-01-01 ~ 09-29)
연가8일
반차7건 = 3.5일 (전부 연차(오전))
대체휴가 사용2일 (1/2, 1/15)
대체근무 적립38일
공휴일 등록18일

잔여 — 연가 15일 중 11.5일 사용, 3.5일 남음. 대체휴가 38일 적립, 2일 사용, 36일 남음.

대체근무 적립 기준은 휴일(토·일·공휴일)에 실제 출퇴근이 찍힌 날 = 1일이다. 엑셀에서 37일이 나왔고, 따로 손으로 넣은 9월 27일(일요일)을 같은 규칙으로 더해 38일이다.

🔴 연가 총 15일은 데카가 넣은 기본값이다. 2026년 실제 연가 일수를 이사장님께 확인해 고쳐야 한다.

5. 레슨

  1. 클라우드플레어가 파이썬 기본 User-Agent 를 막는다(error code: 1010). urllib·requests 기본 UA 로 우리 사이트를 HTTPS 로 부르면 브라우저 지문 차단에 걸린다. 로컬 127.0.0.1 시험은 멀쩡한데 라이브만 전부 실패하는 모양으로 나타나 원인을 엉뚱한 데서 찾게 된다. 시험 하네스에 보통 브라우저 UA 를 한 줄 넣어라.

  2. HTTP 헤더에는 한글을 넣을 수 없다. CSV 내려받기의 Content-Disposition 에 한글 파일이름을 그대로 넣었더니 starlette 이 latin-1 인코딩에서 터져 500 이 났다. filename= 에는 영문 이름을, 한글은 filename*=UTF-8''<percent-encoded> 쪽에만 넣는다.

  3. 근태 원자료에는 반드시 자정을 넘긴 날이 있다. 이번 엑셀에도 퇴근 칸이 익일 05:33, 출근 칸이 익일 02:30 인 행이 있었다. 시각을 [:5] 로 자르는 순진한 파싱은 익일 0 같은 값을 만들고, 그게 DB 에 들어가면 집계 화면 전체가 500 으로 죽는다(한 행이 전부를 망친다). ① 파싱에서 「익일」을 다음 날 날짜로 옮기고, ② 표시 계층은 망가진 값이 와도 견디게 만들어라.

  4. 반차 쓴 날의 오후 출근이 지각으로 잡힌다. 승인된 휴가가 걸린 날은 지각·조퇴를 세면 안 된다. 이걸 안 잡았으면 6월 지각이 756분으로 보고됐을 것이다(실제는 36분). 근태 집계를 만들 때 출퇴근 기록과 승인된 휴가를 반드시 교차시켜라.

  5. 월간보고 엑셀은 다음 달 1일을 한 줄 더 물고 있다. 9개 파일을 그냥 이으면 8일이 중복된다. 날짜를 키로 중복을 제거하되, 값이 있는 쪽을 우선해야 한다.

  6. 지번 주소는 무료 지오코더로 안 풀린다. 「완도군 완도읍 군내리 59-8」이 OSM 에 없고 VWorld·카카오는 키가 필요하다. 그래서 중심 좌표를 설정값으로 빼고 현장에서 「지금 내 위치를 중심으로」 단추 한 번으로 확정하는 구조로 만들었다. 좌표를 못 구해 멈추지 말고, 사람이 현장에서 찍게 설계하는 편이 낫다.

  7. 터널에 호스트네임을 더하는 것은 안전하다. 지우는 것이 없기 때문이다. 다만 cloudflared 재시작은 필요하고 그 몇 초 동안 같은 터널의 모든 호스트가 끊긴다. 스크립트는 기본이 「보기」 모드여야 한다.

6. 미완료

  1. [이사장님] 사무실에서 work.sakyowon.co.kr → 관리 → 설정 → 「📍 지금 내 위치를 중심으로」 를 한 번 누른다. 지금 좌표는 완도읍 중심 임시값(중심확정=0)이라 화면에 경고가 떠 있다. 이걸 하기 전에는 반경 400m 판정이 실제 사무실 기준이 아니다.
  2. [이사장님] 2026년 연가 총 일수를 확인해 알려준다. 지금은 기본값 15일이 들어가 있다.
  3. [이사장님 또는 데카] 직원 등록. 등록하면 초기 PIN(번호 뒤 4자리)이 화면에 뜬다. 직원별 근무요일·출퇴근시각·근무 비율·연가 일수를 여기서 정한다.
  4. [이사장님] 퇴근이 빠진 날 2건(2026-05-26, 2026-08-31)과 시각이 아예 없는 1건(2026-05-22)을 기억나는 대로 채운다. 관리 → 빠진 기록 찾기에서 바로 된다.
  5. [데카] 직원이 여러 명 붙은 뒤 「빠진 기록 찾기」가 매달 말에 자동으로 돌아 텔레그램으로 알리게 붙이면 좋다. 지금은 사람이 눌러야 본다.
  6. [데카] 근태 시험 하네스를 영구 위치로 옮긴다. 이번 것은 세션 임시 폴더에 있었다.
